# 2026-W46 每週精選：Agent 走出終端機，人仍握著開關

> 本週（11/10～11/15）是這份清單的第一週。創刊號之後，每日更新共新收錄 15 個專案，以下挑出最值得看的 5 個。

## 本週精選

- **[DIYgod/pinky](https://github.com/DIYgod/pinky)** · 瀏覽器與電腦操作
  透過 MCP 讓 Agent 操作真的 iPhone 或 Android 手機。付款等高風險步驟要你按允許，銀行與密碼管理 App 預設對 Agent 隱藏，這些規則由閘道執行，不靠提示詞。目前仍是 pre-alpha。
- **[devvmhq/devvm](https://github.com/devvmhq/devvm)** · 程式開發 Agent
  每個專案資料夾一台獨立虛擬機，預設只能連到允許的網域。想放更多權限給 Agent、又不想讓它碰到整台電腦的人，可以從這裡開始。
- **[alexeyw/lot-map](https://github.com/alexeyw/lot-map)** · 程式開發 Agent
  把 Claude Code 的工具呼叫、hook、子 Agent 畫成即時地圖，context 用量一眼就看得到。適合想知道 Agent 時間都花在哪裡的人。
- **[agentes-chat/agentes-chat](https://github.com/agentes-chat/agentes-chat)** · 無程式碼平台與自架介面
  可自架的團隊聊天軟體，Agent 是頻道成員，有負責人和預算，敏感動作要在聊天室核准。AGPL-3.0，需自備模型金鑰。
- **[nishuzumi/show-me-you-want-skill](https://github.com/nishuzumi/show-me-you-want-skill)** · 外掛、技能與其他清單
  讓程式 Agent 寫程式前先畫出線框原型給你改，確認後才動工，把需求溝通的成本移到寫程式之前。

## 趨勢觀察

本週新專案有兩條明顯的線。第一條是 Agent 的活動範圍往外擴：從終端機延伸到手機（pinky、phoneuse）、Windows 桌面（sandbox-mcp）和團隊聊天室（agentes-chat）。伴隨而來的是一致的設計：隔離環境、權限閘道、核准卡片，讓人在關鍵步驟出手，而不是全部放手或全部盯著。

第二條是 Agent Skill 的題材越來越多樣。週末收錄的 6 個 Skill 涵蓋改寫英文、做解說影片、線稿動畫、3D 遊戲、把書轉成教練，還有寫程式前先畫原型。這些 Skill 多半不只是提示詞，還附帶腳本、函式庫和檢查步驟，並在關鍵階段停下來等使用者確認。
