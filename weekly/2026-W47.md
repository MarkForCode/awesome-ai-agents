# 2026-W47 每週精選：替 Agent 量身改造工具，也讓人更容易接手

> 本週（11/16～11/22）已合併的每日更新加上今天，共新收錄 14 個專案（11/18～11/21 的更新還在等待合併，不列入本週）。以下挑出最值得看的 5 個。

## 本週精選

- **[paul-nameless/agweb](https://github.com/paul-nameless/agweb)** · 瀏覽器與電腦操作
  用 WebKit 做給程式 Agent 用的 macOS 瀏覽器，視窗不搶鍵盤焦點，每個動作直接回報頁面變動，登入和驗證碼可以交還給你處理。同時跑好幾個 Agent 的人最有感。限 macOS 26 以上。
- **[hridaya423/phonedriver](https://github.com/hridaya423/phonedriver)** · 瀏覽器與電腦操作
  把 Android 或 iPhone 畫面轉成編號清單讓 Agent 操作，只回傳變動項目以節省 token。付款、刪除帳號等按鈕會被攔下由你決定，模型無法代答。AGPL-3.0。
- **[claynicholson/copper-kicad-mcp](https://github.com/claynicholson/copper-kicad-mcp)** · MCP 伺服器與 SDK
  讓 Agent 從一句需求開始畫電路圖、查現貨零件、佈線，每次修改都重跑 ERC/DRC，最後輸出能下單打樣的製造檔。是本週離軟體最遠、也最具體的 MCP 應用。
- **[JimLiu/open-artifact](https://github.com/JimLiu/open-artifact)** · 外掛、技能與其他清單
  Agent 做的投影片、設計稿、試算表可以在本機網頁直接修改、留言、匯出，留言再送回 Agent 繼續改。不綁定特定 Agent，Claude Code、Codex、Copilot 都能用。
- **[sybil-solutions/skill-distill](https://github.com/sybil-solutions/skill-distill)** · 外掛、技能與其他清單
  由前沿模型當老師，讓開放權重模型反覆重做同一件事、比對成果、修正 Skill，直到學生追上原本的結果。把「寫 Skill」變成一個有測試的流程。

## 趨勢觀察

本週第一條線是把現有工具改成 Agent 好用的形式。agweb 和 turbo-browser-mcp 都在減少瀏覽器操作的 token 與來回次數，phonedriver 對手機做同樣的事，copper-kicad-mcp 則把 KiCad 的檢查流程變成 Agent 每一步的回饋。共通點是只回傳變動的部分，並且把高風險步驟留給人決定。

第二條線是 Agent 做完之後的交接。open-artifact 讓成品可以直接修改，ui-diff 把介面變化整理成審查者看得懂的 PR 留言，skill-distill 把一次成功的工作變成可重複的 Skill。多 Agent 分工（numbrone、git-twig、PiBot）也持續出現，重點同樣放在每個 Agent 改了什麼要看得到。
