# 2026-11-26 沒有 Mac 也能讓 Agent 測 iOS App

> 今天收錄 4 個專案。最大的亮點是在 Linux 上跑 iOS 模擬器、給 Agent 操作的 agent-sim。另外三個都是在幫 AI 產出的東西把關或加工：一個檢查 Rust 程式碼結構，一個檢查介面有沒有對齊，一個讓 Agent 做出工程圖風格的 3D 解說頁。

## 今日新收錄

- **[Developing-Gamer/agent-sim](https://github.com/Developing-Gamer/agent-sim)** · 瀏覽器與電腦操作
  過去要讓 Agent 測 iOS App 幾乎都得有一台 Mac，agent-sim 建立在 x86Sim 上，把 iOS 模擬器搬到一般的 x86 Linux 虛擬機，再加上命令列、MCP 伺服器和瀏覽器即時畫面。操作方式跟之前收錄的 phonedriver 類似，把畫面讀成編號清單、點完直接回傳新畫面，還能開好幾支手機給多個 Agent 輪流用。作者自己標示仍在早期，硬體需求也不低，App Store 下載的加密 App 不能跑。
- **[deterministic-machines/deslop-please](https://github.com/deterministic-machines/deslop-please)** · 程式開發 Agent
  一般 linter 管的是單行寫法，這個管的是模組之間的關係：循環依賴、某個結構的欄位在一堆模組裡被直接存取、對外開放太多函式。概念來自《A Philosophy of Software Design》的「深模組、窄介面」。README 附了一段可以貼進 AGENTS.md 的指示，要求 Agent 從設計上修，不要只是把程式碼搬來搬去讓錯誤消失。目前只支援 Rust。
- **[pritamux/gridlines](https://github.com/pritamux/gridlines)** · 外掛、技能與其他清單
  範圍很窄的 Skill，只做一件事：在介面上畫垂直參考線，量出文字、圖示的實際邊緣，列出差了幾個像素的項目，再去調 padding。附的探測腳本也可以直接貼到瀏覽器 console 用，不一定要透過 Agent。跟 unslop-anything 這類整體檢查相比，它更適合在收尾時做一次細部對齊。
- **[Moh4696/inkworks-skill](https://github.com/Moh4696/inkworks-skill)** · 外掛、技能與其他清單
  讓 Agent 用 three.js 做出像工程圖的互動解說頁，例如四缸引擎怎麼運作，讀者可以暫停、一步一步看、拖動循環圖表。所有零件都是程式碼畫的，不用模型檔或生成影片，每個動作都由同一個角度帶動，所以逐格播放很精準。附了引擎和打氣筒兩個範例，可以照著寫自己的機構。
