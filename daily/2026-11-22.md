# 2026-11-22 Agent 交出來的東西，要看得到、改得動

> 今天收錄 5 個專案，多數在處理 Agent 做完之後的事：成品怎麼讓人直接修改、介面改了什麼怎麼給審查者看、做得好的流程怎麼交給便宜的模型重複執行。另外有一個桌面版的多 Agent 團隊，以及一份從防禦方角度整理的 Agent 攻擊偵測規則。

## 今日新收錄

- **[JimLiu/open-artifact](https://github.com/JimLiu/open-artifact)** · 外掛、技能與其他清單
  叫程式 Agent 做投影片或設計稿，通常拿到的是一堆 HTML 檔，想改個標題還得再叫它一次。Open Artifact 讓 Agent 照固定格式寫出資料夾，由本機服務開成可以直接編輯、留言、匯出 PDF 或 PPTX 的頁面，留言還能一鍵送回 Agent 的工作階段。前身是 baoyu-design，這次改成不綁定特定 Agent 的格式，Claude Code、Codex、Copilot 都有外掛。
- **[sybil-solutions/skill-distill](https://github.com/sybil-solutions/skill-distill)** · 外掛、技能與其他清單
  一般寫 Skill 是寫完就算，這個 Skill 則讓前沿模型當老師，在 tmux 裡開學生模型（例如本機的開放權重模型）從乾淨狀態重做同一件事，比對成果、找出學生第一個出錯的地方再修 Skill，每個版本跑三次。最後由你看並排結果決定是否接受。想把一次性的好結果變成便宜模型也做得到的流程，可以參考它的做法。
- **[imuratalpay/ui-diff](https://github.com/imuratalpay/ui-diff)** · 程式開發 Agent
  Agent 改前端時，審查者往往只看得到程式碼差異。ui-diff 會找出受影響的頁面，在暫時的 worktree 裡分別跑起修改前後的版本截圖，凍結時鐘、亂數和動畫讓截圖穩定，再把差異整理成一則固定更新的 PR 留言。截圖存在同一個 repo 的孤立分支，不會外流到圖床。
- **[w01fb0ss/PiBot](https://github.com/w01fb0ss/PiBot)** · 無程式碼平台與自架介面
  以 pi Agent 核心做成的桌面 App，可以建立不同角色的 Bot，拉進群組由協調者擬計畫、你確認後才分派。所有工具呼叫都經過同一套權限規則，指令在沙箱裡跑，核准與對外傳送的內容會寫進稽核紀錄。專案剛公開、只有一位開發者，適合先試用觀察。
- **[ThreatDefence/agentic-attack-detections](https://github.com/ThreatDefence/agentic-attack-detections)** · 外掛、技能與其他清單
  開源的 AI 滲透測試框架已經被拿來做真實入侵，這份 repo 從防禦方整理每個框架的偵測規則和入侵指標，也把共通行為（例如關掉核准提示的 Agent 連續執行攻擊工具）抽出來寫成通用規則。適合資安團隊直接匯入，也能讓 Agent 開發者了解自己的工具被濫用時會長什麼樣子。
