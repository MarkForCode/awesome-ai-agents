# 2026-11-19 Agent 從螢幕走進實體世界，也開始幫你清硬碟

> 今天收錄 4 個專案。最受注目的是 Google DeepMind 的機器人 Skill，讓程式 Agent 從 MuJoCo 模擬一路做到真的機械手臂。另外一個工具專門清理平行跑 Agent 留下的 worktree 和建置檔案，兩個 Skill 則分別處理網頁上的動態插圖和日文寫作。

## 今日新收錄

- **[google-deepmind/robotics-antigravity-plugin](https://github.com/google-deepmind/robotics-antigravity-plugin)** · 外掛、技能與其他清單
  你用自然語言描述任務，Agent 寫控制程式、在 MuJoCo 模擬裡反覆測試，再把同一份程式放到 SO-101、YAM 等實體手臂上執行。沒有硬體也能只玩模擬，例如照幾張照片重建工作台場景。主要為 Google Antigravity 設計，但也能用 `npx skills` 安裝到其他 Agent；視覺感知的部分要 Gemini API key，操作實體機器人時 README 也特別提醒要守在旁邊、隨時能斷電。
- **[morajabi/poo](https://github.com/morajabi/poo)** · 程式開發 Agent
  前天收錄的 git-twig 是從建立 worktree 的時候就開始省空間，poo 則是事後清理：每個 Agent worktree 各自的 `node_modules`、Rust `target`、Xcode DerivedData，還有已合併的 worktree、舊模擬器和舊版 Agent CLI。它依「刪掉後多麻煩」把項目分級，正在建置或有 Agent 在跑的專案不碰，移除 worktree 前會先 stash 未提交的變更。附的 MCP 伺服器預設只讓 Agent 試跑，實際清理範圍也受你設定的等級限制。
- **[nilbuild/stick-scene](https://github.com/nilbuild/stick-scene)** · 外掛、技能與其他清單
  跟之前收錄的 line-art-animation 類似，都是讓 Agent 畫網頁用的小動畫，這個走火柴人路線，用來說明產品的功能。Agent 會先讀專案、提兩三個構想讓你選，寫完後逐格渲染檢查有沒有重疊或被裁掉。成品是沒有相依套件的單一 canvas，畫面外不繪製，開啟「減少動態效果」時只顯示靜態畫面。
- **[AnIT012/nihongo](https://github.com/AnIT012/nihongo)** · 外掛、技能與其他清單
  讓 AI 寫的日文少一點「AI 感」：拿掉「結論：」「背景：」這類標籤、不在內部聊天裡堆過重的敬語，但給長輩或正式公告的文字仍保留該有的禮貌。分成每次都載入的精簡版（約 2,500 token）和寫對外文件時才讀的完整版，也能貼幾段自己的文章讓它學你的寫法。README 明列禁止用於詐騙與冒名。
