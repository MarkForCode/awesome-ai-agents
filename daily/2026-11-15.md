# 2026-11-15 四個 Agent Skill：先畫原型再寫程式，把書變成教練

> 今天收錄 4 個 Agent Skill，都是放進 Claude Code、Codex 等程式 Agent 的 skills 資料夾就能用。一個在動手前先畫線框讓你確認，一個做線稿動畫，一個把整本書轉成 Skill，一個帶 Agent 從零做出瀏覽器 3D 遊戲。

## 今日新收錄

- **[nishuzumi/show-me-you-want-skill](https://github.com/nishuzumi/show-me-you-want-skill)** · 外掛、技能與其他清單
  遇到會改介面或 API 的需求時，Agent 先讀程式碼、寫一份 spec，再產生可以離線開啟的單檔 HTML 原型，黃框是修改、綠框是新增、紅框是刪除。你可以在圖上拖動元件、寫批注，再一鍵複製意見貼回對話，按下「確認方案」後 Agent 才開始寫程式。跟只用文字描述的 plan mode 比，比較容易在動工前發現「它理解錯了」。
- **[JDhruv14/line-art-animation](https://github.com/JDhruv14/line-art-animation)** · 外掛、技能與其他清單
  Skill 搭配四個不需要相依套件的 TypeScript 模組，負責筆觸、步態、彈簧與風、日夜配色，讓 Agent 畫出會走路、能點擊互動的線稿 SVG 場景。流程上會先給你看一個角色，確認後才做完整場景，也會逐格檢查動作。附了一個日本街景範例，可以直接跑起來看效果。
- **[bookleme/bookleme](https://github.com/bookleme/bookleme)** · 外掛、技能與其他清單
  把書轉成兩種 Skill：可以查詢的知識包，或照著書中流程一問一答的教練。每條引文都要能在原文逐字找到，並有限制引用比例的著作權檢查，不通過就不安裝。核心只用 Python 標準庫，部分體裁還在路線圖上，第三方書籍產生的 Skill 預設不公開。
- **[op7418/guizang-game-skill](https://github.com/op7418/guizang-game-skill)** · 外掛、技能與其他清單
  作者把用 Agent 做出仙俠 3D 動作遊戲《霧鎖山門》時踩過的坑整理成 Skill，涵蓋先問清需求、接上素材生成工具、調整打擊手感、最後打包成單一 HTML。README 很坦白，說明這不是一句話就能做出成品，要多輪試玩回饋。採 AGPL-3.0 授權，搭配 Tripo、即夢等服務效果較好，沒有的話會改用免費素材。
