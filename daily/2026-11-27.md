# 2026-11-27 Agent 走出瀏覽器，開始操作整台電腦

> 今天收錄 5 個專案。重點是 Vercel Labs 的 agent-desktop：它不靠截圖，而是讀作業系統的無障礙介面，讓 Agent 操作一般桌面 App。另外兩個是幫平行跑的程式 Agent 省時間、整理 Skill 的工具，最後是 LangChain 的常駐 Agent 範例，以及一套讓 Agent 做小遊戲的工具組。

## 今日新收錄

- **[vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop)** · 瀏覽器與電腦操作
  它把 macOS、Windows、Linux 的無障礙樹讀成帶編號的 JSON，Agent 照編號點擊，做完再讀一次確認結果。不用像素比對，預設也不會搶滑鼠和視窗焦點。工具裡沒有內建模型，迴圈由你自己的 Agent 跑，可以用 CLI、MCP 或 C 函式庫呼叫。缺點是沒做好無障礙支援的 App 就讀不到元件。
- **[ertembiyik/xcslot](https://github.com/ertembiyik/xcslot)** · 程式開發 Agent
  讓多個 Agent 各開一個 worktree 平行做 iOS App 時，每個新 worktree 都得重新編譯一次，因為 Xcode 只在路徑和檔案時間都相同時才會沿用建置資料。xcslot 準備幾個固定路徑的建置槽，把 worktree 同步進去再建置。作者在 IceCubesApp 上測到第一次建置從 85 秒降到 3.9 秒，用法就是在原本的 xcodebuild 前面加上 `xcslot`。
- **[chipfighter/lodestar](https://github.com/chipfighter/lodestar)** · 外掛、技能與其他清單
  Skill 裝多了以後，模型每個對話都會看到全部的 Skill。Lodestar 在對話一開始跳出選單讓你挑一組，之後這個對話只載入那一組，也不會破壞 prompt cache。分組可以直接叫 Claude 幫忙整理，子 Agent 也能指定自己的組合。
- **[langchain-samples/Persistent-Agent](https://github.com/langchain-samples/Persistent-Agent)** · 研究與通用 Agent
  LangChain 示範「主動型」Agent 的完整範例，放在 Slack 裡給整個團隊用：記住每個人的目標並在背景推進、晚上整理記憶、旁聽頻道在幫得上忙時才開口。比起拿來直接用，更適合當參考架構。注意它建立在 LangSmith 的託管服務上，需要付費方案。
- **[nexu-io/opengame](https://github.com/nexu-io/opengame)** · 外掛、技能與其他清單
  一套 Skill 加 MCP 伺服器，讓程式 Agent 從 25 個遊戲範本改出自己的版本。比較有意思的是驗證環節：自動跑邏輯檢查、用不同玩法路線模擬難度、在無頭瀏覽器實際操作試玩，最後錄出預告片。README 行銷味很重，素材生成也要另外付 API 費用，建議先從內建範本試起。
