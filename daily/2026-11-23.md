# 2026-11-23 給 Agent 立規矩，也讓它記住做過的事

> 今天收錄 5 個專案。兩個處理「Agent 每次都從頭來」的浪費：Coral 把跑通的工具呼叫存成可重用的程式碼，AgentRun 讓 Agent 跑完留下筆記和 Skill。另外有瀏覽器廠商聯手維護的前端 Skill、可以自架的 Slack 程式 Agent，以及只把慢的函式交給 Agent 改寫成 Rust 的工具。

## 今日新收錄

- **[GoogleChrome/modern-web-guidance](https://github.com/GoogleChrome/modern-web-guidance)** · 外掛、技能與其他清單
  程式 Agent 寫前端時常拿出好幾年前的寫法，例如用 JavaScript 硬做原生 Popover 或 View Transitions 就能處理的效果。這份 Skill 由 Chrome、Edge、Firefox 和 MDN 團隊一起維護，Agent 需要時才用 CLI 查對應的指南，內容會依評測結果刪掉模型本來就會的部分以節省 token。另外附 `legacy-scan` 指令，可以掃出既有專案裡能換掉的舊寫法。
- **[withcoral/coral](https://github.com/withcoral/coral)** · MCP 伺服器與 SDK
  多數 MCP 閘道只能決定 Agent 看得到哪些工具，Coral 則讓 Agent 寫短短的 TypeScript 去呼叫服務，每一次底層呼叫都會比對允許、詢問、封鎖的規則，通過才補上憑證。跑成功的程式碼可以存成自訂工具，例如「只關閉 30 天沒動靜的工單」，權限因此能比單一 API 更細。個人可以用桌面版，團隊版需要自備 OIDC 和反向代理。
- **[diggerhq/opencomputer](https://github.com/diggerhq/opencomputer)** · 程式開發 Agent
  在 Slack 裡 @ 它就會開一個工作階段，交給 Claude Code、Codex 或 OpenCode 處理，每個工作階段用 rootless Podman 隔離，狀態存進以 git 為底的儲存區。跟其他雲端程式 Agent 相比，最大的差別是整套 Apache-2.0 開源、可以自架在自己的 VM 上。目前自架還需要 Cloudflare Workers，其他平台尚未支援。
- **[EL4CTEO/fast-anything](https://github.com/EL4CTEO/fast-anything)** · 程式開發 Agent
  不建議整個專案改用 Rust 重寫，而是先剖析找出最耗時的函式，交給 Claude Code 或 Codex 只改寫那幾個。比較值得參考的是驗證流程：錄下最多 500 次真實呼叫，再加上 NaN、空字串、非 ASCII 等邊界案例，全部結果一致、而且真的比較快才會換上，隨時可以一個環境變數切回原版。支援 Python、Node、Ruby、Go、Java 等多種語言。
- **[Parcha-ai/agentrun](https://github.com/Parcha-ai/agentrun)** · 無程式碼平台與自架介面
  不取代你慣用的 Agent，而是包在 Claude Code、Codex、OpenCode 或 pi 外面，補上執行紀錄、伺服器重開後續跑、核准與花費上限。每次跑完 Agent 會留下筆記、Skill 或固定流程，讓下一次同樣的工作少走冤枉路。README 舉的案例（例如自建程式碼審查每次成本降到約 0.18 美元）是開發團隊自己的數據，實際效果要用自己的工作驗證。
