# 2026-11-28 Agent 開始幫你測 App、畫圖、做影片

> 今天收錄 4 個專案。最大的是 Prime Intellect 的 Prime Agent，把所有動作都寫成 Python 程式碼，還能依執行紀錄修改自己的補充設定。另外三個是把 Agent 用在寫程式以外的工作：一組在手機模擬器上當新使用者測試 App，一個畫會自己檢查排版的架構圖，一個做解說短片。

## 今日新收錄

- **[PrimeIntellect-ai/prime-agent](https://github.com/PrimeIntellect-ai/prime-agent)** · 程式開發 Agent
  跟一般程式 Agent 一次呼叫一個工具不同，它只給模型一個常駐的 Python REPL，讀檔、跑指令、開子 Agent 都寫成程式碼，子 Agent 的結果也直接回傳成變數。`/refine` 會回顧這次的執行過程，修改補充提示、記憶和 Skill，但不會動到基本系統提示。官方明講它會用你的權限執行程式碼，而且不是沙箱，最好在獨立的 worktree 裡跑。
- **[pierridotite/mobile-agent-testers](https://github.com/pierridotite/mobile-agent-testers)** · 程式開發 Agent
  用 GitHub Actions 的免費 runner 開 iOS 模擬器和 Android 模擬器，每台由一個 Claude Code Agent 扮演不同使用者，例如瑞典文介面配最大字級的 iPhone SE、阿拉伯文的 Pixel，像新使用者一樣操作 App，回報附截圖的 bug。作者在 LocalSend 上用 20 台跑了一輪，找到 46 個問題，模型費用約 4.6 美元。Android 上發現的操作路徑還能轉成 Maestro 測試重跑。
- **[lukendeasy/open-diagram](https://github.com/lukendeasy/open-diagram)** · MCP 伺服器與 SDK
  Agent 畫的架構圖常有文字擠在一起、線條穿過區塊的問題。open-diagram 先依字型量好每個標籤的寬度再排版，產生時檢查間距和線條路徑，有問題會直接說是哪兩個區塊撞在一起，Agent 可以照著修。可以當 Python 套件用，也能用 MCP 接進 Claude Code，還能匯入 Mermaid 流程圖。
- **[petergyang/video-explainer](https://github.com/petergyang/video-explainer)** · 外掛、技能與其他清單
  給它一個主題、文件或程式碼庫，它會寫腳本、抓網路素材、配上字幕和音樂，輸出約一分鐘的 1080p 影片。完成後會在瀏覽器開一個預覽頁，可以停在任一格留意見再改。旁白和配樂可以在本機免費產生，要用 Gemini 的語音和音樂就需要付費 API 金鑰。
