# 2026-11-21 Skill 開始各司其職：框架官方、遊戲美術、3D 列印都有了

> 今天收錄 5 個專案，其中三個是 Skill：NestJS 官方出了一套，另外兩個分別用在像素遊戲美術和 3D 列印，後者的設計重點是讓 1.7B 的小模型也做得出可用的成品。另外兩個，一個是 Replit 開源的自架個人 Agent，一個是替 Google Antigravity 減少來回輪數的 MCP 外掛。

## 今日新收錄

- **[replit/amuse](https://github.com/replit/amuse)** · 研究與通用 Agent
  一個人在自己電腦上用的全能助理：查資料、操作瀏覽器、設提醒、追蹤目標，還能做出存有資料的小工具。比較用心的是權限設計，寄信、送出表單、付款或新增排程前都會跳出確認卡，可以選只允許這次、這個任務、這個網站或永遠允許；帳密存在加密保險箱，模型只看得到代號。只支援 OpenAI 模型，沒有登入機制，README 明講不要開放到網路上。
- **[INK-Q/agy-fast](https://github.com/INK-Q/agy-fast)** · 程式開發 Agent
  作者分析了自己 55 個 Antigravity 工作階段，發現慢的主要原因是每一輪都要等第一個 token，不是模型輸出太慢，所以這個 MCP 外掛把多次搜尋、同一檔案的多處編輯和驗證合併成一次呼叫。依作者自己的紀錄，同樣的工作量大約少了三分之一的輪數。注意它內建背景自動更新，會自行從 GitHub 下載新版本。
- **[nestjs/agent-skills](https://github.com/nestjs/agent-skills)** · 外掛、技能與其他清單
  框架官方自己寫 Skill，好處是能補上模型訓練資料裡還沒有的新 API。六個 Skill 依工作切分，從開新專案、寫端點、驗證授權、資料庫、測試到上線；比較實用的是列出「測試會過但其實有問題」的錯誤，例如登入流程洩漏哪些 email 已註冊。可以用 npx 安裝，也能從 Claude Code 的外掛市集裝。
- **[danielwh2/sprite-stacking](https://github.com/danielwh2/sprite-stacking)** · 外掛、技能與其他清單
  Sprite stacking 是獨立遊戲常見的假 3D 技法，這個 Skill 讓 Agent 從四張正交視角的像素圖切出分層，再組成可以旋轉的物件；手邊沒有圖像生成工具時，Agent 也會自己用 Python 畫。附的網頁檢視器可以轉、拆開看各層，也能匯出 16 個方向的 sprite sheet，直接放進遊戲用。
- **[baney75/smoothstone](https://github.com/baney75/smoothstone)** · 外掛、技能與其他清單
  作者發現 1.7B 的小模型自己寫 OpenSCAD 幾乎做不出能用的零件，於是改成模型只挑範本、填尺寸，建模和列印檢查（是否封閉、牆夠不夠厚、懸空角度）都交給工具。每個指令最後都會提示下一步，模型就算忘光前面的對話也能接著做。作者的盲測裡小模型 40 次成功 39 次；需要 OpenSCAD 2026 以上版本，目前要裝 nightly 版。
