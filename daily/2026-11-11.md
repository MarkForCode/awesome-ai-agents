# 2026-11-11 讓 Agent 查資料庫，別再「SQL 能跑但答案錯」

> 這天原本選了 4 個專案，其中 3 個（pinky、devvm、sandbox-mcp）已併入 [11-12 的更新](https://markforcode.github.io/awesome-ai-agents/daily/2026-11-12.html)，這裡只留下另一個：處理 Agent 查資料庫時最怕的「查詢跑得動、數字卻是錯的」。

## 今日新收錄

- **[gogoymh/auto-ontology-mcp](https://github.com/gogoymh/auto-ontology-mcp)** · 記憶與上下文
  把 NVIDIA Auto Ontology 的語意層做成 MCP 伺服器，理解與撰寫 SQL 交給你本來在用的模型，伺服器負責驗證並以唯讀方式執行。另外也能把收據、筆記整理成可查詢的個人知識庫，並匯出成 Obsidian 筆記庫。不需要另外架模型端點或設定 API key。

有想推薦的專案？歡迎到 [GitHub](https://github.com/markforcode/awesome-ai-agents/issues) 開 issue。
