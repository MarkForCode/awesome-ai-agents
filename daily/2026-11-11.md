# 2026-11-11 給 Agent 一個可以亂來的地方：手機、虛擬機與拋棄式 Windows

> 這週冒出好幾個「讓 Agent 動手，但限制它能碰到什麼」的專案：有的把 Agent 關進虛擬機，有的讓它操作手機但關鍵步驟要人按允許。今天收錄 4 個，三個跟隔離與把關有關，另一個處理 Agent 查資料庫時最怕的「SQL 能跑但答案錯」。

## 今日新收錄

- **[DIYgod/pinky](https://github.com/DIYgod/pinky)** · 瀏覽器與電腦操作
  透過 MCP 讓 Claude Code、Codex 等 Agent 操作真實的 iPhone 或 Android 手機。跟一般手機自動化工具不同的是，付款、傳訊這類步驟由 Pinky 的閘道攔下等你核准，Agent 沒辦法自己放行，銀行和密碼管理 App 也預設看不到。目前還是 pre-alpha。
- **[devvmhq/devvm](https://github.com/devvmhq/devvm)** · 程式開發 Agent
  在專案資料夾執行 `devvm`，就會開一台只掛載這個資料夾的 Lima 虛擬機，依專案檔自動裝好工具鏈，再讓 Agent 在裡面跑。網路預設只放行允許清單上的主機，token 也留在主機端，比直接在自己電腦上開放 Agent 執行指令安心得多。
- **[shanselman/sandbox-mcp](https://github.com/shanselman/sandbox-mcp)** · MCP 伺服器與 SDK
  Scott Hanselman 做的工具，用 Windows Sandbox 開一台全新的 Windows，讓 Agent 部署程式、操作介面，測完就整台刪掉。適合抓「少裝一個執行環境就當掉」這類問題，但需要 Windows Pro 以上版本。
- **[gogoymh/auto-ontology-mcp](https://github.com/gogoymh/auto-ontology-mcp)** · 記憶與上下文
  把 NVIDIA Auto Ontology 的語意層做成 MCP 伺服器，理解與撰寫 SQL 交給你本來在用的模型，伺服器負責驗證並以唯讀方式執行。另外也能把收據、筆記整理成可查詢的個人知識庫，並匯出成 Obsidian 筆記庫。

有想推薦的專案？歡迎到 [GitHub](https://github.com/markforcode/awesome-ai-agents/issues) 開 issue。
