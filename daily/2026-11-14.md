# 2026-11-14 把 Agent 拉進團隊頻道，也把它的工作過程攤開來看

> 今天收錄 4 個。一個讓 Agent 跟同事一起待在聊天頻道裡、照規矩做事，一個把 Claude Code 每一步的動作畫成即時地圖，另外兩個是 Agent Skill：一個改寫 AI 味太重的英文，一個用程式碼做出有旁白的解說影片。

## 今日新收錄

- **[agentes-chat/agentes-chat](https://github.com/agentes-chat/agentes-chat)** · 無程式碼平台與自架介面
  可自架的 Slack 替代品，Agent 是工作區的成員而不是側邊欄機器人：各有角色、負責人和每月預算，沒被 @ 的訊息由路由器決定交給哪個 Agent。合併、部署和 MCP 連接器標記為敏感的動作，會在聊天裡等負責人核准。採 AGPL-3.0 授權，自架免費，模型金鑰自備。
- **[alexeyw/lot-map](https://github.com/alexeyw/lot-map)** · 程式開發 Agent
  Claude Code 外掛，在對話旁畫出一張地圖：讀檔、跑指令、連網、子 Agent 各是一個站點，每次呼叫都會飛出一道脈衝，錯誤和被 hook 擋下的呼叫標成紅色，中間的圓環顯示 context 用了多少。比起捲動一長串指令紀錄，更容易看出 Agent 把時間花在哪裡。作者說明它不連網、不讀檔，標籤只顯示名稱不顯示內容。
- **[Dodaios/ste80-humanizer](https://github.com/Dodaios/ste80-humanizer)** · 外掛、技能與其他清單
  分兩步改寫英文：先刪掉 26 種常見的 AI 寫作痕跡，再參考航太維修手冊用的 ASD-STE100 規則，把句子拆成一句一個意思、改用主動語態。一般「去 AI 味」工具多半只換掉字詞，它多做了句子結構這一步，並強調不增刪事實。目標是讓人讀得懂，不是躲過 AI 偵測。
- **[Moh4696/cinematic-skill](https://github.com/Moh4696/cinematic-skill)** · 外掛、技能與其他清單
  跟 Agent 說「做一支 90 秒的萊特兄弟紀錄片」，它會寫腳本、錄旁白、從 Wikimedia Commons 找公有領域照片並記下授權，再用 Python 逐格畫出一鏡到底的影片。畫面全由程式碼產生而不是 AI 生成影片，所以每次輸出都一樣，換一段配音也會自動重新對時。腳本、風格和 30 秒草稿三個階段會停下來等你確認。
