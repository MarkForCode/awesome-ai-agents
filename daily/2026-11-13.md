# 2026-11-13 看得見 Agent 在做什麼：從即時地圖到團隊聊天室

> 今天收錄的 3 個專案都在處理同一件事：讓人更容易看到、也接得住 Agent 的工作。一個把 Claude Code 的每一步畫成地圖，一個讓 Agent 直接進團隊頻道工作，另一個用 AirPlay 加藍牙讓 Agent 操作 iPhone。

## 今日新收錄

- **[alexeyw/lot-map](https://github.com/alexeyw/lot-map)** · 程式開發 Agent
  Claude Code 外掛，在對話旁邊畫一張地圖：讀檔、跑指令、連網、叫子 Agent 時，對應的站點會亮起來，出錯或被 hook 擋下會變紅，中間的圓環顯示 context 用了多少。比起往上捲一長串工具呼叫紀錄，更容易看出 Agent 把時間花在哪裡。資料只在本機，介面有 7 種語言。
- **[agentes-chat/agentes-chat](https://github.com/agentes-chat/agentes-chat)** · 無程式碼平台與自架介面
  可自架的團隊聊天軟體，Agent 跟同事一樣是頻道成員，各自有負責人和每月預算；合併、部署這類動作會變成聊天室裡的核准卡片，等人按了才執行。它把 MCP、排程任務、記憶、Wiki、任務看板都放進同一個地方，跟在 Slack 外掛機器人相比，Agent 的工作過程大家都看得到。採 AGPL-3.0，模型金鑰要自備，部分功能還在 beta。
- **[lxe/phoneuse](https://github.com/lxe/phoneuse)** · 瀏覽器與電腦操作
  畫面用 AirPlay 鏡像到電腦，輸入則讓電腦扮成藍牙滑鼠鍵盤，所以 iPhone 不用越獄也不用接線。跟昨天收錄的 Pinky 比，它專攻 iPhone、走的是硬體層的路線，可以設定 Agent 接手前先在手機上問你。目前是 alpha，Linux 支援最完整，Mac 需要另買一塊開發板當橋接器。
