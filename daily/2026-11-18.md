# 2026-11-18 先錄下行為再改寫，也讓 Agent 做設計前先想清楚

> 今天收錄 5 個專案。共同點是替 Agent 加上「檢查點」：rust-anything 用錄下來的行為驗證每一段改寫，craft 和 antialgorithm 讓 Agent 在交出設計前先停下來檢查。另外有 Hugging Face 用上千個 Agent 寫出純規則聊天機器人的實驗，以及一個讓 Agent 用程式碼做影片的引擎。

## 今日新收錄

- **[erkamyaman/rust-anything](https://github.com/erkamyaman/rust-anything)** · 程式開發 Agent
  叫 Agent「改寫成 Rust」最怕的是改完行為悄悄變了。rust-anything 先錄下原程式對各種輸入的實際輸出，Agent 每移植一塊就重播比對，全部相符才往下走，以 MCP 伺服器和 Skill 的形式接進 Claude Code、Codex、Cursor、Gemini CLI。README 很誠實地列出它抓不到的情況，例如沒錄到的輸入、不同語言的正規表示式差異，也提醒小函式改用 Rust 呼叫反而可能更慢。
- **[huggingface/pybot](https://github.com/huggingface/pybot)** · 研究與通用 Agent
  Hugging Face 讓一千多個 Agent 只能用 if-else、正規表示式和查表寫聊天機器人，跑了五千多個版本，最後得到約 64 萬行程式碼加 55 萬行測試，在他們的評測上跟 SmolLM-360M-Instruct 差不多。它不是實用工具，價值在於展示大規模 Agent 協作能把一件事推到多遠，也能直接 clone 下來在終端機裡聊。
- **[diego3g/craft](https://github.com/diego3g/craft)** · 外掛、技能與其他清單
  跟昨天收錄的 unslopovich 事後挑毛病不同，craft 管的是動手前：先一題一題訪談你寫出 DESIGN.md，做畫面時要列出所有狀態（空的、載入中、出錯），用既有的設計系統元件，交件前再自我審查。支援 Figma、Paper、pen.dev 或純 HTML，Claude Code 裝成外掛後會自動依需求分派到對應的 Skill。
- **[staryone/motlab](https://github.com/staryone/motlab)** · 外掛、技能與其他清單
  每一幕影片就是一個 canvas 網頁，Agent 依照你給的 logo、截圖、配樂寫出場景，你在檢視器裡框選畫面或時間段留言，Agent 逐條修改。全程不用 AI 影像模型，作者測試在有 GPU 時輸出速度是 Remotion 的 2 到 4 倍。環境需求不少：Node 24、Chrome、ffmpeg 都要裝。
- **[mankidev/antialgorithm](https://github.com/mankidev/antialgorithm)** · 外掛、技能與其他清單
  模型做創意工作時容易挑最平均的答案。這個 Skill 要它先講出「最普通的選項」，再依專案條件刻意偏離，另附隨機起點產生器和 SVG 版面檢查腳本。README 的對照圖中，有用 Skill 的那排是從十幾次結果裡挑出來的，看效果時要考慮這點。
