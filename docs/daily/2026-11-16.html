2026-11-16 給 Agent 的專用工具：不搶焦點的瀏覽器、會畫 PCB 的 MCP

今天收錄 4 個專案，有三個在處理同一件事：把現有工具改造成更適合 Agent 使用的形式。兩個瀏覽器工具都把重點放在減少 token 和來回次數，另一個讓 Agent 直接操作 KiCad 畫電路板。最後一個是會因為事件自動醒來的終端機 Agent。

今日新收錄

  • paul-nameless/agweb · 瀏覽器與電腦操作
    作者同時跑好幾個程式 Agent，受不了 Playwright 的 Chrome 視窗一直搶走鍵盤焦點，就用 WebKit 寫了這個 macOS 瀏覽器。指令刻意沿用 playwright-cli 的名稱，每個動作執行完會直接回報頁面哪裡變了，不必再拍一次快照；登入、驗證碼可以用 ask 交給你處理，密碼可以從 1Password 等工具讀取，不會出現在對話紀錄裡。限制是只能用在 macOS 26 以上，也沒有 Chrome DevTools Protocol。
  • Tthanh2k6/turbo-browser-mcp · 瀏覽器與電腦操作
    跟 agweb 想解決的問題類似，但走 MCP 路線、底層仍是 Playwright。它把細碎的點擊、填欄位合併成批次工具，點擊後只回傳變動的部分，上傳檔案時直接給磁碟路徑、不用把 Base64 塞進 context，按下送出前預設也會先停下來等人確認。README 裡的 token 節省數字是作者自己的基準測試，專案也還很新，可以拿來跟 microsoft/playwright-mcp 比較看看。
  • claynicholson/copper-kicad-mcp · MCP 伺服器與 SDK
    讓 Agent 從「做一塊 USB-C 供電的 ESP32-C3 板子」這種描述開始，畫電路圖、到 LCSC 查現貨零件、擺放佈線，每次修改後都重跑 KiCad 的 ERC/DRC，最後輸出可以下單打樣的 Gerber 與 BOM。伺服器本身不呼叫模型，用哪個模型由你的 AI 工具決定。需要 KiCad 10，Windows 測試最完整。
  • pmndrs/pine · 研究與通用 Agent
    出自 react-three-fiber 背後的 pmndrs 團隊。多數 Agent 要等你下指令，pine 則可以訂閱資料夾、網站、webhook、MQTT 等事件，例如「掃描資料夾每多一個檔案，就整理出摘要和付款資訊」。設定檔不必自己寫，由主 Agent 透過對話建立子 Agent、MCP 和排程；終端機介面支援分頁、圖片與拖放。目前支援 macOS 與 Linux。
