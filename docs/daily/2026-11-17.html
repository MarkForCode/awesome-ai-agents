今天收錄 5 個專案。一個讓程式 Agent 直接操作 Android 和 iPhone，兩個處理「同時開很多個 Agent」時會遇到的問題：硬碟空間和任務分派。另外兩個是 Skill，一個檢查 AI 做出來的介面，一個帶 Agent 調校本機推論伺服器的速度。

今日新收錄

  • hridaya423/phonedriver · 瀏覽器與電腦操作
    把手機畫面轉成編號清單交給 Agent，點完之後只回傳有變動的項目，不用一直截圖，作者自己測的 token 用量比 mobile-mcp 少很多。比較特別的是付款、刪除帳號等按鈕會被攔下來，由你在 Claude Code 的提示裡決定，模型本身無法代答。採 AGPL-3.0 授權，付款偵測靠按鈕文字，只有圖示的按鈕抓不到。
  • leostera/git-twig · 程式開發 Agent
    讓 Agent 平行工作時，每個 worktree 都是一份完整的程式碼，大型 repo 很快就吃掉硬碟。git-twig 在 APFS、Btrfs 等檔案系統上用寫入時複製建立 worktree，作者的測試在 Linux kernel 上省下約 40 倍空間。小 repo 建立反而變慢，ext4 則會直接改用一般的 git worktree。
  • stevenmichaelthomas/numbrone · 程式開發 Agent
    架在 herdr 終端機工作區上的三層分工：總管 Agent 接需求並分派到專案，經理 Agent 開工人 Agent 在獨立 worktree 裡做事，再一層層回報。整套只有一個 Skill、一個 bash 腳本和幾份 Markdown 角色說明，狀態也存成純文字，想調整很直接。需要先裝 herdr。
  • erkamyaman/unslopovich · 外掛、技能與其他清單
    不只挑紫色漸層這類「AI 感」設計，作者分析了大量 App 商店評論，先檢查使用者真正在抱怨的事，例如按鈕沒反應、錯誤訊息講不清楚、廣告打斷操作。可以只給評分報告，也可以直接修改並附上前後對照。README 也講明它不會測效能，報告會標示「Not profiled」。
  • sybil-solutions/inference-optimisation-skill · 外掛、技能與其他清單
    重點不是給一份參數清單，而是一套流程：先算理論上限，一次只改一個設定、前後都跑對照組，最後還要通過長 context 檢索測試才算數。附的 Python 腳本能對任何 OpenAI 相容伺服器做測速，適合自己架 vLLM、SGLang 或 llama.cpp 的人。
